Ghost Canvas Frontline is the visual workspace for **Ghost Canvas**, a platform for GUI-focused automation and MCP tool creation. It gives users a place to work with the product and review its visual results, while the core automation implementation remains in the main Ghost Canvas project.

## What Frontline is for

- A clear, visual entry point to the Ghost Canvas experience.
- A workspace for working with graphical applications and automation tasks.
- A way to view and review visual results.

This repository contains the Frontline interface. It is not a description of the core product's implementation or operating procedures. For the product's high-level context, see the [Ghost Canvas main repository](https://github.com/ksbicorp/Ghost-Canvas).

## Project status

Frontline is an accompanying interface for Ghost Canvas. Refer to the main project for current product information. Do not treat this repository alone as a specification of the complete platform.
